# freelance tax copilot (india)

an agent that answers tax questions for indian freelancers - GST registration, presumptive tax, TDS, advance tax - from structured, sourced content in Sanity. every answer is pinned to a tax year and cites the section it came from.

work in progress for the DEV x Sanity challenge.
